## What Grok Bot actually is

An agent with its own persistent cloud computer: desktop, filesystem, terminal, apps.
Not a chatbot. Not this Grok chat. Not Grok Build CLI.

Three ways to talk to a Bot (Grok Bot 101):

1. Chat
2. Routines and triggers
3. Other Bots

Stand-up time they claim: 10–15 minutes. Teach once. Reuse.

## Official field rules we now treat as law

- Name, Title, Description. That is the Bot.
- Rules are a prompt, not JSON.
- One login, every Bot. Shared computer.
- Hand the desktop back for 2FA, CAPTCHA, password, API key.
- Link payments only after Shawn approves. Not this week.
- Specialists, not one omniscient Bot. Cap three unless Ara says yes.
- One group chat: Galaxy Week. Roster Shift Lead + Bench + Signal + Shawn.
- Reuse before create. Channel cap 6.
- Skill first. Routine second.
- Teach by demonstration when the path is clicks.
- Grok Bot is the outer loop. Cursor cloud agents write the code.
- Eng manager does not code. Shift Lead routes. Bench builds.
- Overnight task per Bot so morning is ready.
- Bot-to-Bot handoff without routing through the human.
- Templates are a recipe, not a clone. Night 3 ship is Share as Template after stripping secrets.
- Stay quiet if nothing changed.
